# Plugin WordPress: Pokemones CPT + PokéAPI

Este plugin permite registrar un **Custom Post Type (CPT)** llamado `pokemones`, junto con taxonomías personalizadas `tipo` y `fortaleza`. Integra dinámicamente con la [PokéAPI](https://pokeapi.co) para mostrar y filtrar datos de Pokémon en el frontend mediante un shortcode. También incluye una funcionalidad opcional para importar los primeros 20 Pokémon como entradas del CPT desde el administrador.
